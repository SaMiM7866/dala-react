# Dala landing page (React + Vite)

Frontend-only, no backend.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # output in dist/

Structure:
- src/App.jsx              – page sections + scroll logic
- src/components/Particles – canvas particle animation (brain, bulb, globe, swirl)
- src/components/Team      – team carousel
- src/components/Modal     – "Request access" modal (no data is sent anywhere)
- src/data.js              – team, investors, section config (edit content here)
- src/styles.css           – all styles
